# Restart MinIO Algorithm Services

## 1. Enter the Service Directory

```bash
cd /data/minio-os/
```

## 2. List Algorithm Services

```bash
docker-compose ps
```

## 3. Restart an Algorithm

```bash
docker-compose restart omchat
```

> `omchat` is the algorithm name. Use `docker-compose ps` to find and substitute another name.
