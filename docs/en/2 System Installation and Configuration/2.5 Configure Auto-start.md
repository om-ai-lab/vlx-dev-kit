# 2.5 Configure Auto-start at Boot

On Ubuntu, applications can be started automatically in several ways. This section describes two common methods; choose one according to your application and system environment.

## Configure an Auto-start Service with init.d

1. Create a startup script.

   Use a text editor to create a script in `/etc/init.d`. This example uses `your_script_name`; replace the name and program path for your application:

   ```bash
   #!/bin/bash

   ### BEGIN INIT INFO
   # Provides:          your_service_name
   # Required-Start:    $all
   # Required-Stop:
   # Default-Start:     2 3 4 5
   # Default-Stop:      0 1 6
   # Short-Description: Start your_service_name at boot time
   # Description:       Enable service provided by your_service_name
   ### END INIT INFO

   /path/to/your/program &

   exit 0
   ```

2. Make the script executable.

   ```bash
   sudo chmod +x /etc/init.d/your_script_name
   ```

3. Register the script with `update-rc.d` so it is included in the boot sequence.

   ```bash
   sudo update-rc.d your_script_name defaults
   ```

4. Enable the service at boot with `systemctl`.

   ```bash
   sudo systemctl enable your_script_name
   ```

5. Reboot the board and check the service status to verify that the application starts correctly.

   ```text
   root@ubuntu:~# systemctl status your_script_name.service
   ● your_script_name.service - LSB: Start your_service_name at boot time
        Loaded: loaded (/etc/init.d/your_script_name; generated)
        Active: active (exited) since Wed 2023-04-19 15:01:12 CST; 57s ago
          Docs: man:systemd-sysv-generator(8)
       Process: 2768 ExecStart=/etc/init.d/your_script_name start (code=exited, status=0/SUCCESS)
   ```

## Configure Startup Commands with rc.local

`rc.local` is a service script used during system startup. Commands added to it run automatically at boot and can start applications or perform other initialization.

On older Linux distributions, `rc.local` usually ran as the final startup script. With systemd, this is a compatibility method; confirm that the corresponding service is enabled before using it.

Edit `/etc/rc.local` and add the required startup commands before `exit 0`, for example:

```bash
#!/bin/bash -e
#
# rc.local
#
# This script is executed at the end of each multiuser runlevel.
# Make sure that the script will "exit 0" on success or any other
# value on error.
#
# In order to enable or disable this script just change the execution
# bits.
#
# By default this script does nothing.

# Insert what you need

exit 0
```
