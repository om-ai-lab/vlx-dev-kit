# 2.1 Create a System Disk

## 1. Download the System Disk Tool

Ventoy can create a USB drive containing multiple ISO versions. You can install different operating systems from one drive without re-flashing it; simply copy the required ISO file to the prepared drive.
http://192.1.3.110:8080/ventoy-1.1.05-windows.zip

## 2. Download the ISO File
```bash
wget https://developer.nvidia.com/downloads/embedded/L4T/r39_Release_v2.0/iso/jetsoninstaller-r39.2.0-2026-06-01-23-53-13-arm64.iso
```
## 3. Run the Disk-creation Tool
Step 1: Select the inserted USB drive and click Install.
