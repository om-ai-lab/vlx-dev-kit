# 2.3 Network Configuration

## 1. Open Network Settings

Click 1 (the network icon), then 2 (Settings).
<img
     src="https://minio.om-agent.cn/hzlh/otaApifox/image%20(9).png
" alt="Network settings" width="1000 "/>



## 2. Configure Ethernet

After connecting an Ethernet cable, click 1 `network` and then 2 Settings.




![image (10).png](https://minio.om-agent.cn/hzlh/otaApifox/image%20(10).png)

## 3. Obtain an IP Automatically

If the network provides `dhcp`, an IP address is assigned automatically.

![image (11).png](https://minio.om-agent.cn/hzlh/otaApifox/image%20(11).png)

## 4. Set an IP Manually

Without `dhcp`, manually assign an IP in the appropriate subnet.

![image (12).png](https://minio.om-agent.cn/hzlh/otaApifox/image%20(12).png)

## 5. Configure Wi-Fi

Wi-Fi settings are configured in the same way as on a standard `Win10` system.


![image (13).png](https://minio.om-agent.cn/hzlh/otaApifox/image%20(13).png)

![image (14).png](https://minio.om-agent.cn/hzlh/otaApifox/image%20(14).png)
## 6. View the Local IP

Open a terminal and view the IP address.

![image (15).png](https://minio.om-agent.cn/hzlh/otaApifox/image%20(15).png)

## 7. List All IP Addresses with ifconfig

![image (16).png](https://minio.om-agent.cn/hzlh/otaApifox/image%20(16).png)

To filter for a specific IP, run:
`ip a| grep -w "$(ls -1 /sys/class/net/ | grep -vE 'cali|docker|flannel|br-|lo|veth|virb|tap|l4tb')"| awk '/inet / {split($2, a, "/"); print a[1]}'`
