# 2.4 Install Algorithm Programs

## Step 1: Download the Package

```bash
wget https://hzlh.oss-cn-hangzhou.aliyuncs.com/public/lv-image/t5000-minio-os.tar.gz
```

## Step 2: Extract the Archive

```bash
tar -zxvf t5000-minio-os.tar.gz
```

## Step 3: Install
Run `cd minio-os && bash install.sh` to install.
```bash
cd minio-os && bash install.sh
```
Model download URLs are listed in README.md. Currently, only the VLX-Seek and OPN models are required.
