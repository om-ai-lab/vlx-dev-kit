# 2.2 Install the System
## Step 1

Power on the VLX board, connect an Ethernet cable, and perform the initial setup.

## Step 2

Press F11 during boot and select the installation disk.


![image (8).png](https://minio.om-agent.cn/hzlh/otaApifox/06de0f49-d5b4-494d-a2bc-824dedae8fa3.png)

## Step 3

After selecting the disk, accept the default options throughout the installation.

Continue until the system page appears and set a username and password.


![image (8).png](https://minio.om-agent.cn/hzlh/otaApifox/image%20(8).png)
