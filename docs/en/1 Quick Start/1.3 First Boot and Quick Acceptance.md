# 1.3 First Boot and Quick Acceptance

This chapter describes the complete process from powering on the VLX Development Module to functional acceptance. Following these steps verifies the core capabilities in **10 minutes**.

1. Connect and power on the device. Obtain its IP address from the display or router.

2. Open the device address in a browser and replace the initial self-signed certificate. Set an administrator password on first login.

3. Activate the license. When online, enter the activation code directly. When offline, export a request file, obtain the device license (`license.vlx`) from the VLX Licensing Portal, and import it into the device.

4. Open **Device > Camera**, select a compatible camera, and run a preview test.

5. Open **Model > VLX-Seek**, start the inference service, enter a target description, and run the standard demo.


### Initial Acceptance Criteria

The table lists acceptance criteria and verification methods for the permanent runtime and annual upgrade service entitlements.

| Item | Pass criteria | Verification |
| --- | --- | --- |
| First boot | Device reaches the `VLX-Seek` demo within 10 minutes | Check the first-boot event timestamp |
| Licensing | A valid device activates successfully; a copied license cannot be used on another device | Review license audit records and error codes |
| Offline operation | After activation, disconnect the network and reboot; `VLX-Seek` continues to run normally | Disconnect network and reboot |
| Model output | With a standard image, the model returns target regions, confidence, and timestamp | Inspect the API response and save a screenshot |
| Upgrade and rollback | Valid packages install; corrupted packages are rejected; failed upgrades roll back automatically | Review upgrade records and rollback results |
