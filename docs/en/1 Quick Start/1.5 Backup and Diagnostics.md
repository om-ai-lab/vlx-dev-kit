# 1.5 Backup and Diagnostics

Regular backups and proactive diagnostics are essential for reliable long-term operation. This chapter introduces backup policies, command-line tools, and built-in diagnostics.

## Backup Policy

|  |  |  |
| --- | -- | --- |
| Configuration backup | User and API configuration | Encrypted; excludes models and device keys |
| Business backup | Database and task records | Supports manual and scheduled runs; integrity must be verified |
| System recovery | Restore the VLX Factory Bundle | Requires a second confirmation before clearing business data |

### Command-line Backup Tool

```bash
# Create a full encrypted backup
vlx-backup create --type full --encrypt \
  --output /mnt/usb/backup.vlxbak

# Verify backup integrity
vlx-backup verify /mnt/usb/backup.vlxbak

# Restore from a backup (requires --confirm)
vlx-backup restore /mnt/usb/backup.vlxbak --confirm
```

## Diagnostics and Logs

The built-in health-check engine periodically checks licensing, database, model, GPU, and storage status. When an issue is detected, the health agent automatically restarts services and records an event.

Administrators can view health reports and export a redacted diagnostic package from the “Diagnostics” page. Passwords, keys, raw images, and personal data are removed by default; only version information and redacted logs are retained. **The system does not provide an unredacted export option.**
