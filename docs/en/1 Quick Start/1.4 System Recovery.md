# 1.4 System Recovery

## Recovery Methods

Choose a method according to the scope and severity of the fault. Start with the least disruptive operation and increase the recovery level as needed.

| Method | Scope | Description |
| --- | --- | --- |
| Single-service restart | Restart only the failed service | Triggered automatically by the health agent |
| Version rollback | Restore the previous healthy version | Roll back application and model together; restore the database from backup |
| Database recovery | Restore MySQL data | Restore from the most recently verified backup |
| Factory recovery | Restore the VLX Factory Bundle | Requires a second confirmation before clearing business data |
| License recovery | Re-import `license.vlx` | For the same device only; cannot be used on another device |
| Diagnostic export | Export version information and redacted logs | Passwords, keys, images, and personal data are removed by default |

## Recovery Priority

When an abnormality occurs, try recovery in the following order to avoid an unnecessary full reset:

1. Restart the failed service (least impact; the health agent can do this automatically).
2. Roll back to the previous healthy version (also roll back the database or confirm backward compatibility).
3. Restore the database from the most recently verified backup.
4. Restore the VLX Factory Bundle, then re-import the license and business backup.
5. After hardware repair or replacement, perform a manual license migration (technical support approval required).

## Flashing Tool Notes

Select the appropriate flashing method for your scenario.

### Factory or Custom Carrier Recovery

Use the following command:

```bash
sudo ./l4t_initrd_flash.sh <board> internal
```

<strong>Note:</strong> A full flash overwrites the target partitions. Back up business data first.

</div>

### After-sales Standalone Recovery

Use an ISO-bootable USB drive:

1. Prepare a USB drive of at least 16 GB.
2. Write the Jetson ISO to the USB drive.
3. Boot the device from the USB drive and install.

<div style="padding: 12px 16px; background-color: #FFF7E6; border-left: 4px solid #FA8C16; color: #613400;">

<strong>Note:</strong> ISO recovery is supported only on the official NVIDIA DevKit or a carrier board that has passed compatibility validation.

</div>

After flashing:

1. Re-deploy the VLX Factory Bundle matching the system version.
2. If the hardware identity is unchanged, re-import the original device license (`license.vlx`).
3. If the compute module was replaced, perform the manual license migration process.
