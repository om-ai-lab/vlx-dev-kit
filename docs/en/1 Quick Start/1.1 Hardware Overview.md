# 1.1 Hardware Overview
The VLX Development Module consists of an NVIDIA Jetson Thor T5000 system-on-module (SoM) and a custom VLX carrier board. Key hardware specifications are listed below.

## Product Specifications
Parameter | Specification |
| --- | --- |
| Core module | NVIDIA Jetson Thor T5000 |
| Compute | 2070 FP4 TFLOPS |
| CPU cores | 14-core Arm Neoverse-V3AE (64-bit) |
| GPU | NVIDIA Blackwell (2560 cores) |
| AI compute | 2070 FP4 TFLOPS |
| Memory | 128 GB |
| Storage | 1 TB standard (expandable) |
| System | Ubuntu 22.04, JetPack 7.2 |
| Interfaces | I/O: 1× HDMI, 4× Gigabit Ethernet, 2× USB Type-C, 4× USB Type-A, 6× 2-lane MIPI CSI / 4× 4-lane MIPI CSI, 2× GPIO, 4× CAN, 4× UART, 2× I2C, 1× I2S, 1× SP; expansion: 1× miniPCIe, 1× M.2 M 2280, 1× M.2 B 3050, 1× Nano SIM |
| Buttons | 3: 1× Power, 1× Recovery, 1× Reset |
| Wi-Fi (optional) | Available with an added Wi-Fi module |
| 4G/5G (optional) | Available with an added 4G/5G module |
| Power input | DC 9–36 V |
| Dimensions | L×W×H: 130 × 160 × 80 mm |
| Weight | Approximately 1050 g |
| Operating temperature | −40 to +85 °C |
