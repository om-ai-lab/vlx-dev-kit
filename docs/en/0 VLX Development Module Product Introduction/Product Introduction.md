# VLX Development Module
The VLX Development Module is a high-performance edge-computing development board for embodied intelligence, built on the NVIDIA Jetson Thor T5000 module. It comes pre-installed with Om AI Lianhui VLX-series models, providing out-of-the-box target search and multimodal visual question-answering capabilities.

# Documentation Guide

This section introduces the structure of the VLX Development Module documentation so that you can quickly find the instructions and development guides relevant to your current stage.

**1. Product Introduction, Package Contents, and Common Terms**
    Describes the product positioning, hardware platform, and key capabilities; lists the delivered items; and explains common terminology used throughout the documentation.

**2. Quick Start**
    Covers hardware basics, system flashing, first boot and acceptance, system recovery, backup and diagnostics, and license management.

**3. System Installation and Configuration**
    Covers creating installation media, installing the system, network configuration, algorithm installation, auto-start, and system upgrades. It also provides configuration notes for the srpi-config tool, config.txt, thermal settings, and CPU frequency.

**4. Algorithm Application Development**
Describes the APIs for VLX-Flow, VLX-Seek, VLX-Go, OmDet-Turbo open-vocabulary detection, and the OmChat multimodal model, together with Java and Python SDK integration guides.

**5. FAQ**
Summarizes common issues in module usage, system installation and configuration, model API calls, and SDK integration, with troubleshooting and resolution guidance.
