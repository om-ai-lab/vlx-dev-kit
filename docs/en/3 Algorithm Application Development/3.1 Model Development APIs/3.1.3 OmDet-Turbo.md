# 3.1.3 OmDet-Turbo

## API Function

This API detects a single target in an image and returns its bounding box.

Input: an image to analyze. Output: the detected target marked in the image.

## Request
### Endpoint

- Endpoint: `/v2/images/detection/od`

### Method

- `POST`

**Request parameters**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| subList | List | Yes | Capability list |
| - model | String | Yes | Unique algorithm ID (actionid) |
| - configCode | String | No | Configuration ID |
| input | String | Yes | Input image as base64 or image_url (choose one) |
| inputType | String | Yes | Input type: base64 or image_url |
| regionInfo | Object | No | Region of interest |
| - contain | Boolean | Yes | Whether to trigger an alert for the region; true includes region alerts, false excludes them (based on IoU) |
| - positions | List of List | Yes | Three-level array: polygons, points in each polygon (clockwise), and coordinate points `[x, y]` in pixels with the top-left origin |
| videoCode | String | No | Device information |

## Response

**Response fields**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| code | int | Yes | Message code |
| took | int | Yes | Elapsed time in milliseconds |
| error | String | No | Error message |
| data | list | Yes | Result data; fields below are inside data |
| model | String | Yes | Unique algorithm ID (actionid) |
| detectTime | String | No | Detection time |
| videoCode | String | No | Device information |
| bboxList | List of Object | No | Bounding-box list |
| - bbox | List of Int | No | Bounding-box array containing top-left and bottom-right coordinates |
| -- x1 | Int | No | Top-left x coordinate (px) |
| -- y1 | Int | No | Top-left y coordinate (px) |
| -- x2 | Int | No | Bottom-right x coordinate (px) |
| -- y2 | Int | No | Bottom-right y coordinate (px) |
| - conf | List of String | No | Confidence |
| - label | List of String | No | Target label |
| - status | Boolean | No | Whether an alert was triggered |
