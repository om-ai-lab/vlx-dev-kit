# 3.1.4 OmChat API

OmChat is a lightweight in-house multimodal conversational model that accepts image and text input for real-time edge visual Q&A, scene descriptions, and natural-language interaction. It accepts images or video for scene understanding, multi-turn image-text dialogue, and instruction parsing, and returns fluent natural-language text. The WebUI visualizes answers, latency, and runtime status.

## Model Capabilities

### OmChat

| Scenario | Description |
| --- | --- |
| Scene understanding | Describe scenes from images or video |
| Multi-turn dialogue | Pass conversation history for multi-turn Q&A |

## Endpoint

```http
POST {API_ENDPOINT}/os/v2/chat/completions
```

## Authentication

Include an access token in the request headers:

```http
Authorization: Bearer YjI3YjM4OTQyZDczMjZkMWUzYTdAZVpHVWdxdzg=
Content-Type: application/json
```

## Request Parameters

### Basic Parameters

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | Yes | Model ID |
| `messages` | array | Yes | Conversation messages. Put image content and prompts in a `user` message. |
| `stream` | boolean | No | Whether to stream output. This series currently supports non-streaming only; omit or pass `false`. |
| `max_tokens` | integer | No | Maximum number of generated tokens |
| `temperature` | number | No | Generation randomness; lower values are generally more stable |
| `top_p` | number | No | Nucleus-sampling range, usually 0–1 |

### messages Parameter

`messages` is a list of conversation messages. Each message contains:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `role` | string | Yes | Message role; user input must use `user`. |
| `content` | string / array | Yes | Message content. Use an array for image-plus-text input. |

### content Parameter

For multimodal input, `content` is an array containing image and text objects.

#### Image Content

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | Yes | Always `image_url` |
| `image_url` | object | Yes | Image object |
| `image_url.url` | string | Yes | Publicly accessible image URL |

#### Image Requirements

| Item | Description |
| --- | --- |
| Supported formats | JPEG, JPG, PNG |
| Input method | Image URL |
| Requirements | The URL must be accessible and the image clear and recognizable. |

#### Text Content

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | Yes | Always `text` |
| `text` | string | Yes | Text prompt compatible with the selected model |

## Request Example

Call OmChat-QV-2B as follows:

```bash
curl --location --request POST '{API_ENDPOINT}/os/v2/chat/completions' \
  --header 'Content-Type: application/json' \
  --header "Authorization: Bearer YjI3YjM4OTQyZDczMjZkMWUzYTdAZVpHVWdxdzg=" \
  --data-raw '{
    "model": "OmChat-QV-2B",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "image_url",
            "image_url": {
              "url": "https://minio.om-agent.cn/goal/cover/vlxfo1-cats.jpg"
            }
          },
          {
            "type": "text",
            "text": "Hello."
          }
        ]
      }
    ],
    "stream": false,
    "max_tokens": 4096,
    "temperature": 0,
    "top_p": 1
  }'
```

## Response

On success, the API returns the generated result, request ID, elapsed time, and token usage. `message.content` varies by task.

### OmChat-QV-2B Counting Response Example

```json
{
  "code": 200,
  "id": "",
  "took": 497,
  "created": 1739328997,
  "object": "chat.completion",
  "model": "example-model-name",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello, it is a pleasure to help. What can I do for you?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 43,
    "completion_tokens": 14,
    "total_tokens": 57
  }
}
```

## Response Fields

| Field | Type | Description |
| --- | --- | --- |
| `code` | integer | Request status; `200` indicates success |
| `id` | string | Unique request ID for troubleshooting |
| `took` | integer | Elapsed time in milliseconds |
| `error` | string / null | Error message; normally `null` on success |
| `object` | string | Returned object type |
| `model` | string | Model ID actually used |
| `choices` | array | Array of generated results |
| `choices[].message.role` | string | Role of the returned message |
| `choices[].message.content` | string | Text generated by the model |
| `usage.prompt_tokens` | integer | Number of input tokens |
| `usage.completion_tokens` | integer | Number of output tokens |
| `usage.total_tokens` | integer | Total token count |
