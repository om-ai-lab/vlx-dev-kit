# 3.1.2 VLX-Seek Development API

The VLX-Seek series is a vision-language model for image analysis and fine-grained visual perception. It accepts image and text together, searches for targets, and localizes them by returning regions, bounding boxes, confidence, and spatial anchors. In WebUI, enter descriptions such as “find the red helmet” or “box the toolbox to the left of the table” to view results.

## Model Capabilities

| Scenario | Description |
| --- | --- |
| Object detection | Identify objects from a text instruction and return indices and bounding boxes |
| Counting | Identify and count specified targets; return the count, indices, and boxes |
| Fine-grained reasoning and localization | Infer and localize targets from attributes, state, spatial, or ordering relationships |

## API Reference

### Endpoint

```http
POST {API_ENDPOINT}/os/v2/chat/completions
```

### Authentication

Include an access token in the request headers:

```http
Authorization: Bearer YjI3YjM4OTQyZDczMjZkMWUzYTdAZVpHVWdxdzg=
Content-Type: application/json
```

## Request Parameters

### Basic Parameters

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | Yes | Model ID |
| `messages` | array | Yes | Conversation messages. Put image content and prompts in a `user` message. |
| `stream` | boolean | No | Streaming output. This series currently supports non-streaming only; omit or pass `false`. |
| `max_tokens` | integer | No | Maximum generated tokens |
| `temperature` | number | No | Generation randomness; lower values are generally more stable |
| `top_p` | number | No | Nucleus-sampling range, usually 0–1 |
| `bbox_list` | array | No | Manually supplied regions in `[[x1, y1, x2, y2], ...]` format; mainly for `vlx-seek` region tasks |

### messages Parameter

`messages` is a list of conversation messages. Each message contains:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `role` | string | Yes | Message role; user input must use `user`. |
| `content` | string / array | Yes | Message content; use an array for image-plus-text input. |

### content Parameter

For multimodal input, `content` is an array containing image and text objects.

#### Image Content

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | Yes | Always `image_url` |
| `image_url` | object | Yes | Image object |
| `image_url.url` | string | Yes | Publicly accessible image URL |

#### Image Requirements

| Item | Description |
| --- | --- |
| Supported formats | JPEG, JPG, PNG |
| Input method | Image URL |
| Requirements | The URL must be accessible and the image clear and recognizable. |

#### Text Content

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | Yes | Always `text` |
| `text` | string | Yes | Text prompt compatible with the selected model |

## Request Example

### Call VLX-Seek-1.5-3B

The following example uses the 1.5 object-detection template:

```bash
curl --location --request POST '{API_ENDPOINT}/os/v2/chat/completions' \
  --header 'Content-Type: application/json' \
  --header "Authorization: Bearer YjI3YjM4OTQyZDczMjZkMWUzYTdAZVpHVWdxdzg=" \
  --data-raw '{
    "model": "vlx-seek-1.5-3b",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "image_url",
            "image_url": {
              "url": "https://minio.om-agent.cn/goal/cover/vlxfo1-cats.jpg"
            }
          },
          {
            "type": "text",
            "text": "Identify each cat that is not black."
          }
        ]
      }
    ],
    "stream": false,
    "max_tokens": 4096,
    "temperature": 0,
    "top_p": 1
  }'
```

### VLX-Seek-1.5-3B Reasoning and Localization Example

For fine-grained reasoning and localization, `choices[].message.content` follows the prompt requirements. An example:

```text
<think>
Inspect objects relevant to the question and determine which water bottles have no cap.
...
</think>
<answer>
<ground>water bottles without caps</ground><objects><obj21></objects>
</answer>
```

## Response Fields

| Field | Type | Description |
| --- | --- | --- |
| `code` | integer | Request status; `200` indicates success |
| `id` | string | Unique request ID for troubleshooting |
| `took` | integer | Elapsed time in milliseconds |
| `error` | string / null | Error message; normally `null` on success |
| `object` | string | Returned object type |
| `model` | string | Model ID actually used |
| `choices` | array | Array of generated results |
| `choices[].message.role` | string | Role of the returned message |
| `choices[].message.content` | string | Text generated by the model |
| `choices[].result_bbox_list` | array | Detection boxes; each may include `object_index`, `xmin`, `ymin`, `xmax`, `ymax`, and `label` |
| `usage.prompt_tokens` | integer | Number of input tokens |
| `usage.completion_tokens` | integer | Number of output tokens |
| `usage.total_tokens` | integer | Total token count |
