## Integration Methods

### Method 1: Use the .tar.gz Package

With the .tar.gz package, install the SDK with pip, then import `VlxApiClient` from `omai_client`. `VlxApiClient.from_env()` reads environment variables and creates the client.

See the [DingTalk document](https://alidocs.dingtalk.com/i/nodes/N7dx2rn0Jb6dRYeGhZw3vmwoJMGjLRb3) for the `omai-1.0.3.tar.gz` attachment.

### Method 2: Install the omai Package from PyPI
Install the SDK from the package published to the official PyPI repository with `pip install omai`; a specific version may be selected.

**Install:**

```bash
pip install ./omai-1.0.3.tar.gz
```
or
```bash
pip install omai
```

**Import in application code:**

```python
from omai_client import VlxApiClient

# Read configuration from environment variables and create the client
vlx_api_client = VlxApiClient.from_env()
```

All methods accept custom headers. If the key contains `Authorization`, the configured credential is not added.

```python
headers = {
    "Authorization": "Bearer your_custom_token",
};
```

**Usage:**

## Call VLX-Seek

```python
from omai_client import (
    VlxApiClient,
    VlxSeekRequest,
    VlxSeekMessage,
    VlxSeekContent,
    VlxSeekImageUrl,
)


# Call vlx-seek
image_url = VlxSeekImageUrl(
    url="https://example.com/image.jpg"
)

image = VlxSeekContent(
    type="image_url",
    image_url=image_url,
)

text = VlxSeekContent(
    type="text",
    text="Describe the image",
)

message = VlxSeekMessage(
    role="user",
    content=[image, text],
)

# bbox_list: [[28, 54, 481, 387]]
bbox_list = [
    [28, 54, 481, 387]
]

request = VlxSeekRequest(
    model="VLX-Seek",
    messages=[message],
    bbox_list=bbox_list,
    max_tokens=4096,
    temperature=0.0,
    top_p=1.0,
)

response = vlx_api_client.vlx_seek(request)
```

## Call VLX-Flow
### Method 1
Consume outer SSE events and parse `event.data` in application code.

```python
// Start a long-running vlx-flow request

import json

from omai_client import (
    VlxApiClient,
    VlxFlowSource,
    VlxFlowStreamRequest,
    VlxFlowStopRequest,
    VlxStreamEventMessage,
)


# Build request parameters
source = VlxFlowSource(
    path="https://om-agent-test.linker.cc/minio/goal/cover/vlxflow-video01.mp4",
    type=2,
)

request = VlxFlowStreamRequest(
    model="VLX-Flow",
    prompt="Describe the aerial panoramic view in real time, within 20 words",
    system_prompt="",
    interval_seconds=1.0,
    frame_preempt="queue",
    temperature=0.7,
    max_tokens=40,
    source=source,
)

# Optional custom headers; pass None or omit when not needed
headers = None


class VlxFlowHandler:
    def __init__(self):
        self.task_id = None

    def on_event(self, event):
        # Outer SSE event name, such as message, done, error, or ping.
        print("sse event=", event.event)

        # SSE data field containing the server business-message JSON string.
        data = event.data
        print("sse data=", data)

        if not data:
            return

        # Parse data here if application code needs the VLX business payload.
        message = VlxStreamEventMessage.from_dict(json.loads(data))

        # Save taskId; call vlx_flow_stop later to stop the server task.
        if message.taskId is not None and self.task_id is None:
            self.task_id = int(message.taskId)

        print("business event=", message.event)
        print("content=", message.content)

    def on_error(self, throwable):
        # HTTP, stream-read, and parsing errors arrive here.
        print("vlx stream error:", throwable)

    def on_closed(self):
        # Called when the long connection closes (normal, error, or local cancel).
        print("vlx stream closed")


handler = VlxFlowHandler()

# Call vlx-flow (method 1: consume outer SSE events)
call = vlx_api_client.vlx_flow_stream(request, handler, headers=headers)

# Cancels only the local SSE connection; it does not stop the server task.
# In production, cancel when you no longer need data; do not cancel immediately.
call.cancel()

# To stop the server task, call the stop API with taskId.
if handler.task_id is not None:
    vlx_api_client.vlx_flow_stop(
        VlxFlowStopRequest(
            taskId=handler.task_id,
        )
    )
call = vlx_api_client.vlx_flow_stream(request, handler)
```

### Method 2 (Recommended)
Method 2 (recommended) consumes VLX business events directly. The SDK parses SSE data JSON into `VlxStreamEventMessage`; application code need not parse the outer SSE structure.

```python
// Start a long-running vlx-flow request
from omai_client import (
    VlxApiClient,
    VlxFlowSource,
    VlxFlowStreamRequest,
    VlxFlowStopRequest,
)


# Build request parameters
source = VlxFlowSource(
    path="https://om-agent-test.linker.cc/minio/goal/cover/vlxflow-video01.mp4",
    type=2,
)

request = VlxFlowStreamRequest(
    model="VLX-Flow",
    prompt="Describe the aerial panoramic view in real time, within 20 words",
    system_prompt="",
    interval_seconds=1.0,
    frame_preempt="queue",
    temperature=0.7,
    max_tokens=40,
    source=source,
)

# Optional custom headers; pass None or omit when not needed
headers = None


class VlxFlowMessageHandler:
    def __init__(self):
        self.task_id = None

    def on_event(self, message):
        # The SDK has parsed SSE data into VlxStreamEventMessage.
        # Handle VLX business events directly.

        if message.taskId is not None and self.task_id is None:
            self.task_id = int(message.taskId)

        # Business event types include taskCreated, delta, lineBreak, done, error, and stopped.
        event = message.event

        print("taskId=", message.taskId)
        print("event=", event)
        print("frameNo=", message.frameNo)
        print("content=", message.content)

        if event == "delta":
            # Accumulate incremental content, write it to a DB, or forward it to frontend SSE.
            print("Incremental output:", message.content)

        if event == "done":
            # Server task completed.
            print("VLX task completed")

        if event == "error":
            # Server-side business error.
            print("VLX task error:", message.content)

    def on_error(self, throwable):
        # Connection or data-parsing error.
        print("vlx message stream error:", throwable)

    def on_closed(self):
        # Long connection closed; release application resources.
        print("vlx message stream closed")


handler = VlxFlowMessageHandler()

# Call vlx-flow (method 2: consume VLX business events directly)
call = vlx_api_client.vlx_flow_stream_message(request, handler, headers=headers)

# Closes only the local connection; it does not stop the server task.
# In production, cancel when you no longer need data; do not cancel immediately.
call.cancel()

# Stop the server task.
if handler.task_id is not None:
    vlx_api_client.vlx_flow_stop(
        VlxFlowStopRequest(
            taskId=handler.task_id,
        )
    )
call = vlx_api_client.vlx_flow_stream_message(request, handler)
```

### Method 3 (Not Recommended)
Method 3 reads the raw HTTP stream and parses SSE lines in application code. It is not recommended because blocking, connection closure, parsing, and errors must all be handled manually.

Method 3 is a raw-stream reader and is not recommended. The Python SDK does not start a background thread or dispatch business events for it; use `vlx_flow_stream_message` when you only need VLX events.

```python
// Start a long-running vlx-flow request
import json

from omai_client import (
    VlxApiClient,
    VlxFlowSource,
    VlxFlowStreamRequest,
    VlxSseEventParser,
    VlxStreamEventMessage,
)


# Build request parameters
source = VlxFlowSource(
    path="https://om-agent-test.linker.cc/minio/goal/cover/vlxflow-video01.mp4",
    type=2,
)

request = VlxFlowStreamRequest(
    model="VLX-Flow",
    prompt="Describe the aerial panoramic view in real time, within 20 words",
    system_prompt="",
    interval_seconds=1.0,
    frame_preempt="queue",
    temperature=0.7,
    max_tokens=40,
    source=source,
)

# Optional custom headers; pass None or omit when not needed
headers = None

# The raw method does not start a background thread or parse SSE.
# It starts a raw HTTP stream; reading response.iter_lines() is blocking.
response = None

try:
    response = vlx_api_client.vlx_flow_stream_raw(request, headers=headers)

    if response.status_code < 200 or response.status_code >= 300:
        raise RuntimeError(f"vlx stream http error, code={response.status_code}")

    parser = VlxSseEventParser()

    for line in response.iter_lines(decode_unicode=True):
        # The parser aggregates data lines per SSE and returns a complete event at a blank line.
        event = parser.accept_line(line)
        if event is None:
            continue

        # Outer SSE event.
        print("sse event=", event.event)

        # Inner VLX business message.
        data = event.data
        if not data:
            continue

        message = VlxStreamEventMessage.from_dict(json.loads(data))
        print("business event=", message.event)
        print("content=", message.content)

    # Flush once if an event without a trailing blank line remains before close.
    last_event = parser.complete()
    if last_event is not None and last_event.data:
        message = VlxStreamEventMessage.from_dict(json.loads(last_event.data))
        print("last business event=", message.event)

except Exception as e:
    # Closing response may raise a read error; this is usually not a business error.
    raise RuntimeError(e)

finally:
    # Cancel/close the raw HTTP connection.
    if response is not None:
        response.close()
response = vlx_api_client.vlx_flow_stream_raw(request)
from omai_client import (
    VlxApiClient,
    VlxFlowStopRequest,
    VlxFlowUpdateConfigRequest,
)


// Stop vlx-flow
request = VlxFlowStopRequest(
    taskId=888,
)

response = vlx_api_client.vlx_flow_stop(request)



// Update vlx-flow
request = VlxFlowUpdateConfigRequest(
    taskId=888,
    prompt="Detect whether anyone enters the danger zone",
    frame_preempt="preempt",
)

response = vlx_api_client.vlx_flow_update_config(request)

// Read the return value if needed:
success = response.data
```
