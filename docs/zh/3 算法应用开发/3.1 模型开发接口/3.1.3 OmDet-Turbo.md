# 3.1.3 OmDet-Turbo

## 接口功能

该接口可识别图片中单一目标， 返回标注框

输入： 需要识别的图片 输出： 图片中标出识别到的目标。

## 请求信息
### 接口详情

- 请求地址：`/v2/images/detection/od`

### 请求方式

- `POST`

**请求参数**

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| subList | List | 是 | 能力信息列表 |
| - model | String | 是 | 算法唯一标识（使用actionid） |
| - configCode | String | 否 | 配置信息id |
| input | String | 是 | 输入列表，图片 base64 或 image_url，二选一 |
| inputType | String | 是 | 输入类型，可选择 base64/image_url |
| regionInfo | Object | 否 | 选区 |
| - contain | Boolean | 是 | 是否包含选区告警，true包含选区告警，false不包选区含告警(根据iou计算交集比例) |
| - positions | List of List | 是 | 三层嵌套数组：1. 最外层：多边形数组（会绘制多个选区） 2. 中间层：单个多边形的数组（按顺时针可连接一个多边形） 3. 最内层：单个坐标点 [x, y]，每个点由两个坐标值组成 [x, y] （单位：像素px 根据左上角原点坐标系） |
| videoCode | String | 否 | 设备信息 |

## 返回响应

**返回字段**

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| code | int | 是 | 消息码 |
| took | int | 是 | 耗时毫秒 |
| error | String | 否 | 失败信息 |
| data | list | 是 | 结果数据,以下为data内部数据 |
| model | String | 是 | 算法唯一标识，使用actionid |
| detectTime | String | 否 | 识别时间 |
| videoCode | String | 否 | 设备信息 |
| bboxList | List of Object | 否 | 标注框列表 |
| - bbox | List of Int | 否 | 标注框数组，包含左上角和右下角坐标值 |
| -- x1 | Int | 否 | 左上角横坐标，单位px |
| -- y1 | Int | 否 | 左上角纵坐标，单位px |
| -- x2 | Int | 否 | 右下角横坐标，单位px |
| -- y2 | Int | 否 | 右下角纵坐标，单位px |
| - conf | List of String | 否 | 置信度 |
| - label | List of String | 否 | 目标标签 |
| - status | Boolean | 否 | 是否告警 |
