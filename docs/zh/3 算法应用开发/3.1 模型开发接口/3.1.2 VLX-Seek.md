# 3.1.2 VLX-Seek 开发接口

VLX-Seek系列是面向图像分析与细粒度视觉感知的视觉语言模型，支持图像和文本联合输入。负责目标搜索和空间定位，支持根据自然语言指令输出目标区域、Bounding Box、置信度和空间锚点。开发者可通过 WebUI 输入目标描述，例如“找到红色安全帽”或“框出桌子左侧的工具箱”，并直接查看定位结果。

## 模型能力

| 场景 | 说明 |
| --- | --- |
| 目标检测 | 根据文本指令识别图像中的目标对象，并返回目标索引和边界框 |
| 计数 | 识别并统计指定目标，返回数量、索引和相关边界框 |
| 细粒度推理定位 | 根据属性、状态、空间关系或顺序关系推理并定位目标 |

## 接口说明

### 请求地址

```http
POST {API_ENDPOINT}/os/v2/chat/completions
```

### 鉴权方式

请求头中需要携带访问令牌：

```http
Authorization: Bearer YjI3YjM4OTQyZDczMjZkMWUzYTdAZVpHVWdxdzg=
Content-Type: application/json
```

## 请求参数

### 基本参数

| 字段 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 模型 ID |
| `messages` | array | 是 | 对话消息列表。图像内容和文本提示词需放在 `user` 角色消息中。 |
| `stream` | boolean | 否 | 是否使用流式输出。本系列当前仅支持非流式输出，可不传或传 `false`。 |
| `max_tokens` | integer | 否 | 限制模型生成内容的最大 Token 数。 |
| `temperature` | number | 否 | 控制生成结果的随机性。值越小，结果通常越稳定。 |
| `top_p` | number | 否 | 控制核采样范围，取值通常为 0 到 1。 |
| `bbox_list` | array | 否 | 手动传入感兴趣区域，格式为 `[[x1, y1, x2, y2], ...]`。主要用于 `vlx-seek` 的区域类任务 |

### messages 参数

`messages` 是对话消息列表。每条消息包含：

| 字段 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `role` | string | 是 | 消息角色，用户输入固定使用 `user`。 |
| `content` | string / array | 是 | 消息内容。图像和文本联合输入时使用数组。 |

### content 参数

多模态输入时，`content` 为数组，可包含图像和文本对象。

#### 图像内容

| 字段 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 是 | 固定传 `image_url`。 |
| `image_url` | object | 是 | 图像对象。 |
| `image_url.url` | string | 是 | 可公开访问的图像 URL。 |

#### 图像要求

| 项目 | 说明 |
| --- | --- |
| 支持格式 | JPEG、JPG、PNG |
| 传入方式 | 图像 URL |
| 图像要求 | 图像地址需要可访问，图像内容应清晰可识别。 |

#### 文本内容

| 字段 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 是 | 固定传 `text`。 |
| `text` | string | 是 | 与所选模型匹配的文本提示词。 |

## 请求示例

### 调用 VLX-Seek-1.5-3B

以下示例使用 1.5 的目标检测模板：

```bash
curl --location --request POST '{API_ENDPOINT}/os/v2/chat/completions' \
  --header 'Content-Type: application/json' \
  --header "Authorization: Bearer YjI3YjM4OTQyZDczMjZkMWUzYTdAZVpHVWdxdzg=" \
  --data-raw '{
    "model": "vlx-seek-1.5-3b",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "image_url",
            "image_url": {
              "url": "https://minio.om-agent.cn/goal/cover/vlxfo1-cats.jpg"
            }
          },
          {
            "type": "text",
            "text": "识别每个：不是黑色的猫。"
          }
        ]
      }
    ],
    "stream": false,
    "max_tokens": 4096,
    "temperature": 0,
    "top_p": 1
  }'
```

## 返回字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | integer | 请求状态码，`200` 表示请求成功。 |
| `id` | string | 本次请求唯一标识，可用于问题排查。 |
| `took` | integer | 请求耗时，单位为毫秒。 |
| `error` | string / null | 错误信息，请求成功时通常为 `null`。 |
| `object` | string | 返回对象类型。 |
| `model` | string | 本次实际调用的模型 ID。 |
| `choices` | array | 模型生成结果数组。 |
| `choices[].message.role` | string | 返回消息的角色。 |
| `choices[].message.content` | string | 模型生成的文本结果。 |
| `choices[].result_bbox_list` | array | 目标检测框集合。每个元素可包含 `object_index`、`xmin`、`ymin`、`xmax`、`ymax` 和 `label`。 |
| `usage.prompt_tokens` | integer | 输入 Token 数量。 |
| `usage.completion_tokens` | integer | 输出 Token 数量。 |
| `usage.total_tokens` | integer | 总 Token 数量。 |
