# 常见问题

以下汇总开发者和运维团队最常遇到的问题及解决方案。如需进一步帮助，请导出诊断包并联系技术支持。
<span style="color: #1677B3;">Q：</span> **模型启动失败如何排查？**

<span style="color: #009B72;">A：</span> 查看具体错误码，并根据错误码在“诊断”页面查看详细日志：

| 错误码 | 含义 |
| --- | --- |
| `VLX-LIC-001` | 设备尚未激活 |
| `VLX-LIC-002` | 设备身份不匹配 |
| `VLX-LIC-003` | 当前设备没有对应的模型权益 |
| `VLX-MDL-001` | 模型加载失败 |


<span style="color: #1677B3;">Q：</span> **升级失败后如何回滚？**

<span style="color: #009B72;">A：</span> 系统会自动回滚到上一健康版本。数据库不会被自动回滚，而是通过向后兼容方式保持旧版本可用；必要时从已验证备份恢复。回滚后须执行完整健康检查。

<span style="color: #1677B3;">Q：</span> **如何进行离线激活？**

<span style="color: #009B72;">A：</span> 详见第 6.2 节。简要流程：导出请求文件 → 上传至 VLX 授权门户 → 下载设备许可证（`license.vlx`）→ 导入设备。全程无需设备联网。

<span style="color: #1677B3;">Q：</span> **存储空间不足如何清理？**

<span style="color: #009B72;">A：</span> 在“诊断”页面查看存储详情，可清理历史任务记录、旧版升级包和过期日志。清理前建议先执行 `vlx-backup create` 备份。如长期不足，考虑扩展外部存储。

<span style="color: #1677B3;">Q：</span> **如何远程连接设备？**

<span style="color: #009B72;">A：</span> 远程终端默认关闭或仅允许管理网段访问。管理员启用后应使用独立运维账户和密钥认证，禁止共享管理员口令，维护结束后关闭访问。

<span style="color: #1677B3;">Q：</span> **如何导出诊断包？**

<span style="color: #009B72;">A：</span> 在“诊断”页面点击“导出诊断包”，选择范围和脱敏选项后下载，也可通过命令行执行导出。诊断包包含版本号、健康状态和脱敏日志，默认移除密码、密钥、图像和个人数据。
