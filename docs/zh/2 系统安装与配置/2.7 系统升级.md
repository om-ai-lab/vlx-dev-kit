# 2.7 系统升级

<div style="padding: 12px 16px; background-color: #FFF7E6; border-left: 4px solid #FA8C16; color: #613400;">

<strong>注意：</strong>系统升级是高风险操作，涉及应用、模型和数据库的协同变更。请严格按照以下流程执行，任何步骤未通过均不得跳过。

</div>

1. 管理员阅读发布说明，确认硬件版本、当前版本、权益和停机窗口。
2. 执行升级预检，任何未通过项均不得跳过。
3. 生成并验证数据库备份。
4. 选择在线下载或导入离线升级包，系统验签后方可安装。
5. 安装期间保持电源和网络稳定，禁止中断。
6. 健康检查通过后完成升级；升级失败时等待系统自动回滚，请勿重复强制升级。

## 发布说明必填项

每次系统升级发布包均须附带结构化发布说明，至少包含以下内容：

- 组件版本、发布日期和发布通道
- 新增、变更、修复和已知问题
- 硬件和许可证兼容范围
- 数据库变更说明，包括迁移脚本和向后兼容性
- 下载大小、所需空间和预计停机时间
- 升级路径和回滚限制
- 安全公告编号与风险等级
