# VLX开发模组
VLX开发模组是一款面向具身智能领域的高性能边缘计算开发板，基于 NVIDIA Jetson Thor T5000 模组。预装Om AI联汇VLX系列算法模型，为开发者提供开箱即用的目标搜索与多模态视觉问答能力。

# 文档使用指引

下面将对《VLX开发模组》开发者文档的整体内容进行介绍，帮助用户快速了解文档结构，并根据实际使用阶段查找对应的操作说明和开发指南。

**一、产品介绍、包装清单与常见术语**
    介绍VLX开发模组的产品定位、硬件平台和主要能力，列明随设备交付的物料，并解释文档中涉及的常用术语，帮助用户在开始操作前建立对产品的基本认识。

**二、快速开始**
    介绍硬件基础信息、系统烧录、首次启动与快速验收、系统恢复、备份与诊断以及授权管理，帮助用户完成开发模组的首次使用，并掌握设备恢复、状态检查和授权相关的基础操作。

**三、系统安装与配置**
    介绍制作系统盘、安装系统、网络配置、安装算法程序、开机自启动和系统升级等操作，同时提供 srpi-config 工具、config.txt 文件以及 Thermal 和 CPU 频率的配置说明，帮助用户完成系统部署和运行参数配置。

**四、算法应用开发**
介绍VLX-Flow、VLX-Seek、VLX-Go、OmDet-Turbo开放词表目标检测和多模态模型 OmChat的开发接口，并提供Java SDK 与 Python SDK的调用指南，帮助开发者根据业务场景选择模型能力并完成应用集成。

**五、常见问题**
汇总开发模组使用、系统安装与配置、模型接口调用和SDK集成过程中可能遇到的问题，提供相应的排查思路和处理方法，帮助用户定位并解决开发过程中的常见异常。
