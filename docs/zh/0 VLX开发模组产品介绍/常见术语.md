| 统一术语 | 定义 |
| --- | --- |
| VLX开发模组 | 完整产品名称 |
| VLX 开发板 | 简称，指硬件主体 |
| Mini OS | 设备端软件管理栈 |
| OmDet-Turbo| 开放词表目标检测 |
| OmChat | 多模态视觉大模型模型 |
| VLX-Seek | 目标搜索与定位模型 |
| VLX-Flow | 视觉流处理模型 |
| VLX-Go | 移动导航模型 |
| 设备永久运行权 | 运行已获权版本的永久权利 |
| 年度升级服务权益 | 获得有权新版本和标准支持 |
| 客户认领 | 阶段二用户通过 WebUI 输入激活码，绑定权益至设备 |
| 设备许可证（`license.vlx`） | 权益文件 |
| VLX 工厂预装包（Factory Bundle） | 制造和恢复用的基础软件包 |
| Jetson BSP | 操作系统、驱动和板级配置集合 |
| Force Recovery | 通过 Recovery USB 进入的刷机模式 |
| 降级状态 | 授权有效但组件异常 |
| SoM | System on Module，系统级模组 |
| TensorRT | NVIDIA 推理优化引擎 |
