## 产品规格
参数 | 规格 |
| --- | --- |
| 核心模组 | NVIDIA Jetson Thor T5000 |
| 算力 | 2070 FP4 TFLOPS |
| CPU内核 | 14核 Arm Neoverse-V3AE（64位） |
| GPU | NVIDIA Blackwell（2560-core） |
| AI算力 | 2070 FP4 TFLOPS |
| 内存 | 128GB |
| 存储 | 标配1T GB（可自行扩展） |
| 系统 | Ubuntu 22.04，JetPack 7.2 |
| 接口 | I/O接口：1x HDMI、4x 千兆网络、2x USB Type-C、4x USB Type-A、6x 2 Lane MIPI CSI / 4x 4 Lane MIPI CSI、2x GPIO、4x CAN、4x UART、2x I2C、1x I2S、1x SP；扩展接口：1x miniPCIe、1x M.2 M 2280、1x M.2 B 3050、1x Nano SIM |
| 按键 | 3个：1x Power、1x Recovery、1x Reset |
| WiFi（选装） | 支持通过加装 WiFi 模块后实现功能 |
| 4G/5G（选装） | 支持通过加装 4G、5G 模块后实现功能 |
| 电源输入 | DC 9~36V |
| 尺寸 | LWH：130mm * 160mm * 80mm |
| 重量 | 约1050g |
| 工作温度 | -40 ~ +85℃
