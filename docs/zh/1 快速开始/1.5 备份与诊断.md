# 1.5 备份与诊断

定期备份和主动诊断是保障 VLX 开发模组长期稳定运行的关键。本章介绍备份策略、命令行工具以及内置诊断机制。

## 备份策略

|  |  |  |
| --- | -- | --- |
| 配置备份 | 用户和接口配置 | 加密存储，不含模型和设备密钥 |
| 业务备份 | 数据库和任务记录 | 支持手动和计划执行，须校验完整性 |
| 系统恢复 | 恢复 VLX 工厂预装包（Factory Bundle） | 清除业务数据前须二次确认 |

### 命令行备份工具

```bash
# 手动创建完整加密备份
vlx-backup create --type full --encrypt \
  --output /mnt/usb/backup.vlxbak

# 验证备份完整性
vlx-backup verify /mnt/usb/backup.vlxbak

# 从备份恢复（须 --confirm 确认）
vlx-backup restore /mnt/usb/backup.vlxbak --confirm
```

## 诊断与日志

系统内置健康检查引擎，定期检查授权、数据库、模型、GPU 和存储状态。异常时健康代理自动触发服务重启并记录事件。

管理员可在“诊断”页面查看健康报告并导出脱敏诊断包。诊断包默认移除密码、密钥、原始图像和个人数据，仅保留版本和脱敏日志。**系统不提供不脱敏导出选项。**
