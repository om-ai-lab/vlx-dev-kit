# 1.3 首次启动与快速验收

本章介绍VLX开发模组从开箱上电到完成功能验收的完整流程。按照以下步骤操作，可在 **10 分钟内**验证设备的核心能力。

1. 接线并启动设备，通过屏幕或路由器获取设备 IP 地址。

2. 使用浏览器访问设备地址，确认并替换初始自签名证书。首次登录时，需要设置管理员密码。

3. 完成许可证激活。联网状态下可直接输入激活码；离线状态下需导出请求文件，前往 VLX 授权门户获取设备许可证 `license.vlx`，然后将其导入设备。

4. 进入 **设备 > 摄像头** 页面，选择兼容的摄像头并运行预览测试。

5. 进入 **模型 > VLX-Seek** 页面，启动推理服务，输入目标描述并运行标准演示样例。


### 首发验收标准

下表列出了设备永久运行权和年度升级服务权益在验收阶段的通过指标与验证方式。

| 验收项目 | 通过指标 | 验证方式 |
| --- | --- | --- |
| 首次启动 | 设备在 10 分钟内进入 `VLX-Seek` 演示 | 检查首次启动事件的时间戳 |
| 授权 | 合法设备可成功激活；许可证复制到其他设备后无法使用 | 查看授权审计记录与错误码 |
| 离线运行 | 激活后断开网络并重启设备，`VLX-Seek` 仍可正常运行 | 实际断网并重启设备 |
| 模型输出 | 使用标准图像时，模型能够返回目标区域、置信度和时间戳 | 查看接口响应并保存截图 |
| 升级与回滚 | 有效升级包可正常安装；损坏的升级包会被拒绝；升级失败时自动回滚 | 查看升级记录与回滚结果 |
