# 1.2 系统烧录

VLX开发模组基于 NVIDIA JetPack 7.2 / Jetson Linux R39.2 工具链进行系统烧录。量产阶段使用 initrd Recovery USB 方式，售后单机恢复可使用 ISO 启动 U 盘。本章介绍从工厂烧录到售后恢复的完整流程。

## 工厂烧录流程

工厂量产须使用 NVIDIA 官方 initrd 刷机工具，并叠加 VLX 身份注册流程。VLX 工厂预装包（Factory Bundle）在烧录完成后部署，用于完成设备永久运行权的初始配置。

1. 冻结签名系统包、定制板级配置、分区布局和 VLX 工厂预装包。
2. 将设备切换至 Force Recovery 模式，并通过高质量 USB 线连接烧录主机。
3. 使用 `l4t_initrd_flash.sh` 烧录内部存储；完成后复位设备，并验证系统版本和分区。
4. 部署 VLX 工厂预装包，注入设备序列号，由安全芯片生成密钥并注册设备证书。
5. 仅签发工厂短期测试权益，出厂时不预装客户永久许可证。
6. 执行产线验证，包括硬件接口、版本、MiniOS、数据库、授权代理和 VLX-Seek 标准推理。
7. 验证通过后清除工厂凭据并包装入库，将设备状态设置为“待激活”。

### 工厂量产烧录命令

```bash
# NVIDIA 官方量产烧录命令
# 在 Linux_for_Tegra/tools/kernel_flash 目录执行
# <board> 需替换为 VLX 定制载板已冻结的配置名称

sudo ./l4t_initrd_flash.sh --no-flash <board> internal

# --no-flash：生成镜像包
# --flash-only：执行烧录
# --massflash：支持多工位并行烧录

# 刷机后 Thor 会停留在 initrd 提示符，需要手动复位
./tools/board_automation/boardctl -t thor-jetson reset
