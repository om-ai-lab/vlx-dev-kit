# 1.4 系统恢复

## 恢复方式

根据故障范围和严重程度，选择以下恢复方式。建议从影响最小的操作开始，逐步提高恢复力度。

| 恢复方式 | 恢复内容 | 说明 |
| --- | --- | --- |
| 单服务重启 | 仅重启异常服务 | 由健康代理自动触发 |
| 版本回滚 | 恢复至上一健康版本 | 应用和模型双版本回退，数据库从备份恢复 |
| 数据库恢复 | 恢复 MySQL 数据 | 从最近验证通过的备份恢复 |
| 工厂恢复 | 恢复 VLX 工厂预装包（Factory Bundle） | 清除业务数据前须进行二次确认 |
| 许可证恢复 | 重新导入设备许可证 `license.vlx` | 仅限同一设备使用，不可用于其他设备 |
| 诊断包导出 | 导出版本信息和脱敏日志 | 默认移除密码、密钥、图像和个人数据 |

## 恢复优先级

系统出现异常时，按照以下优先级依次尝试恢复，避免不必要的全面重置：

1. 重启异常服务（影响最小，健康代理可自动执行）。
2. 回滚至上一健康版本（须同步回滚数据库或确认向后兼容）。
3. 从最近验证通过的备份恢复数据库。
4. 恢复 VLX 工厂预装包（Factory Bundle），然后重新导入许可证和业务备份。
5. 硬件维修或更换设备后，执行人工许可证迁移（需要联系技术支持审核）。

## 刷机工具说明

根据使用场景选择合适的刷机方式。

### 工厂或定制载板恢复

推荐使用以下命令：

```bash
sudo ./l4t_initrd_flash.sh <board> internal
```

<div style="padding: 12px 16px; background-color: #FFF7E6; border-left: 4px solid #FA8C16; color: #613400;">

<strong>注意：</strong>全量刷机会覆盖目标分区，操作前须备份业务数据。

</div>

### 售后单机恢复

使用 ISO 启动 U 盘进行恢复：

1. 准备容量不小于 16 GB 的 U 盘。
2. 将 Jetson ISO 写入 U 盘。
3. 设置设备从 U 盘启动并进行安装。

<div style="padding: 12px 16px; background-color: #FFF7E6; border-left: 4px solid #FA8C16; color: #613400;">

<strong>注意：</strong>ISO 恢复方式仅适用于 NVIDIA 官方 DevKit，或已经完成兼容性验证的载板。

</div>

刷机完成后：

1. 重新部署与系统版本匹配的 VLX 工厂预装包（Factory Bundle）。
2. 如果硬件身份未发生变化，重新导入原设备许可证 `license.vlx`。
3. 如果更换了计算模组，须执行人工许可证迁移流程。
